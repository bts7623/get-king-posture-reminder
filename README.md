# 😤 get-king-posture-reminder

> 주기적으로 **킹받는 그림**으로 바른 자세를 안내하는 Windows 알림 프로그램

---

## 소개

장시간 PC 작업 중 자세가 틀어지는 걸 방지하기 위해 만들어진 자세 교정 알리미입니다.  
지정한 시간마다 킹받는 만화풍 캐릭터 그림과 함께 자세 교정 메시지가 팝업으로 표시됩니다.

> ⚠️ **Windows 전용입니다.** macOS 및 Linux에서는 동작하지 않습니다.

---

## 주요 기능

- 🕐 **주기 알림** — 설정한 간격(분)마다 자동으로 팝업 표시
- 🎨 **만화풍 애니메이션 그림 6종** — 2프레임 애니메이션으로 생동감 있게 표시
  - 🐢 거북목 경보
  - 🙈 굽은 등 경보
  - 💪 어깨 펴기
  - 🙆 만세 스트레칭
  - 🦒 목 옆으로 기울이기
  - 💜 어깨 으쓱 스트레칭
- 🖼️ **알림 갤러리** — 6종 그림을 슬라이드쇼로 미리 감상 가능
- 🖥️ **멀티 모니터 지원** — 특정 모니터 선택 또는 모든 모니터 동시 표시
- 🔔 **System Tray 상주** — Windows System Tray(알림 영역) 우클릭으로 설정 접근
- ⚙️ **환경 설정** — 알림 간격, 표시 시간, 모니터 선택, 부팅 시 자동 실행
- 🎉 **최초 실행 환영 화면** — 처음 실행 시 환영 애니메이션 표시
- 🔁 **단일 인스턴스 보장** — 중복 실행 시 기존 인스턴스 자동 종료 (스크립트/exe 교차 지원)

---

## 다운로드 및 실행

### 방법 A — exe 바로 실행 ✅ 추천 (Python 불필요)

1. [Releases](https://github.com/bts7623/get-king-posture-reminder/releases) 페이지에서 최신 `.exe` 다운로드
2. 더블클릭으로 실행
3. Windows System Tray(우측 하단 알림 영역)에 아이콘이 나타납니다

### 방법 B — Python 스크립트로 실행

```bash
# 의존성 설치 (최초 1회)
install.bat

# 실행
run.bat
```

---

## 사용 방법

실행 후 우측 하단 **System Tray 아이콘 우클릭** → 메뉴 선택

| 메뉴 | 설명 |
|---|---|
| 지금 알림 보기 | 즉시 팝업 표시 |
| 환경 설정 | 알림 간격, 표시 시간, 모니터 설정 |
| 알림 갤러리 | 6종 그림 슬라이드쇼 |
| 종료 | 프로그램 종료 |
